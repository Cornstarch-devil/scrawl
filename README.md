# scrawl

面向韩语初学者的学习工作台，适合跟课、整理课堂笔记和学习 KPOP：保留原笔记，关联单词、语法与句子卡片，支持歌词同步和音频片段循环。

## 在线体验

[打开 Scrawl](https://cornstarch-devil.github.io/scrawl/)

## 适合谁

- 刚开始学习韩语，需要跟着课程查阅、整理和复习笔记的人。
- 已有自己的教材和课堂笔记，希望保留原文、按课程与知识点学习的人。
- 同时喜欢 KPOP，想结合歌词、歌曲原音和关联笔记学习的人。

## 核心功能

- **保留原笔记**：沿用项目、笔记本和卡片结构，完整显示原笔记、语法分组、例句与句子分节。
- **关联知识**：查看单词、语法和句子之间已有的关联，在歌词中查看对应卡片。
- **课后复习**：搜索笔记、翻卡、完成已有测试，使用“再记一遍”和综合练习温故。
- **结合歌曲学习**：同步显示歌词与音频，支持单句、选段和整曲循环。

当前内容包括 `introduction`、`1A` 和 `ditto`，共 584 张卡片；句子总卡还包含可独立学习的内部句子。网站直接复用现有 Scrawl 的界面与交互代码。

## 如何使用

1. 从左侧栏进入课程项目，展开课次与单词卡、语法卡或句子卡；通过“更多内容”查看其余课次。
2. 阅读和搜索笔记，在“学习”中翻卡，在“测试”中完成已有题目。
3. 使用“再记一遍”温故选中的内容，或在“综合练习”中选择范围、模式和数量。
4. 进入 KPOP，播放 Ditto，点击歌词查看关联内容，使用单句或选段循环反复听。

## 公开版范围

GitHub Pages 提供现有内容和浏览器内的学习交互。问答、文件解析、内容生成、新语音生成及完整备份恢复依赖本地服务，在公开页停用；已保存的歌曲音频和可用朗读缓存随网站提供。

公开页使用独立的浏览器存储，访客的学习操作只保存在自己的浏览器中。仓库包含网站文件和公开内容，不包含本地密钥、数据库、完整备份或原有学习历史。
